# Анализ e-commerce данных (Olist)
## О проекте
Анализ реального датасета бразильского маркетплейса Olist.
Цель: выявить ключевые факторы, влияющие на выручку и удовлетворенность клиентов.

## Данные
- Источник: Kaggle (Brazilian E-Commerce Public Dataset by Olist).
- Объем: 99 441 заказ, 112 650 товаров.
- Использовал 7 таблиц: клиенты, заказы, товары в заказах, платежи, отзывы, товары, переводы категорий на английский язык.
- Актуальность данных: 2016-2018 г.г. (для анализа динамики не использовал данные за 2016 год, так как данные в нем неполные)

## Инструменты
- PostgreSQL 16
- Power BI

## Ключевые выводы
1. **Топ-категории:** Больше всего денег приносят "health_beauty" (1.23 млн) и "watches_gifts" (1.17 млн).
2. **География:** Основной рынок - штат Сан-Паулу (SP) с выручкой 5.2 млн.
3. **Логистика:** Заказы с опозданием получают среднюю оценку 2.57, а вовремя доставленные — 4.29. Задержка снижает лояльность в 1.7 раза.
4. **Оплата:** 78% выручки приносят кредитные карты. Это создает высокую комиссионную нагрузку.
